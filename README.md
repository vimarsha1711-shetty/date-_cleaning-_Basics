Task 27: Date Cleaning Basics

Objective

Standardize inconsistent date formats in retail sales data and identify missing or invalid dates.

Workbook Sheets

• Raw Data: Original sample retail sales records with mixed date formats.
• Working Sheet: Standardized dates in DD-MM-YYYY format where valid, with a status column to flag records for review.
• Issue Log: Lists missing or invalid date values and suggests actions.
• Summary: Shows the task overview and counts of valid, invalid, and missing dates.

Work Completed

1. Reviewed the date values in the dataset.
2. Converted valid dates into a consistent DD-MM-YYYY format.
3. Flagged missing dates.
4. Flagged invalid dates for review.
5. Created an issue log and summary sheet.

Important Note

This workbook was prepared using sample retail sales data because the original task dataset was not provided. Replace the sample records with the official dataset if Veda Technology requires it, then recheck the date formats and issue log.

Tools Used

• Microsoft Excel

Result

The workbook demonstrates basic date cleaning, standardization, and issue tracking.
